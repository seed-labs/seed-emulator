# Semantic fault drivers

This package owns benchmark meaning. LLM output is an untrusted `FaultCapabilityProposal`; a driver verifies it against pure topology and read-only operation evidence, emits a target-bound `FaultCapabilityBinding`, and deterministically supplies the Scenario fragment. Tool Service operation modules contain no fault selection logic.
