# Benchmark documentation

本目录保存 benchmark 的规范性设计文档。代码行为与文档不一致时，不能只修改代码。

## 文档索引

- `NEW_SCENARIO_DEVELOPMENT_GUIDE.md`：新场景开发的首要规范。
- `GENERATOR_AGENT_DESIGN.md`：生成 Agent 总体设计。
- `TOPOLOGY_GENERATOR_DESIGN.md`：声明式拓扑与编译设计。
- `FAULT_PLATFORM_DESIGN.md`：可扩展故障平台设计。
- `SOFTWARE_FAULTS.md`：软件能力和软件故障模型。
- `PROMOTION_PIPELINE.md`：候选、pilot、晋级与发布机制。
- `BENCHMARK_ACCEPTANCE_CRITERIA.md`：benchmark 完成和验收标准。

新增或重命名规范文档时更新本索引。跨层架构、CLI、证据格式或安全门禁变化时，同时更新对应代码层 README。
